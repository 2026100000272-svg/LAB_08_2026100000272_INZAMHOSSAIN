## What is Version Control?
Version control is a system which keeps a record of and monitors the changes made to files over time.
## What is Git?
Git is a version control system that is free and open-source. 
## What is GitHub?
GitHub is a platform based in the cloud which allows developers to store, manage, and keep track of their software code.
## What is Git Bash?
Git Bash is a software to communicate with git.
